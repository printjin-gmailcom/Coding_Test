# **Coding Test Repository**

## 개요

이 레포지토리는 부트캠프 및 인턴십 과정에서 경험한 코딩 테스트 문제들의 답안 코드와 코딩 테스트 준비를 위한 **리트코드(Leet Code)**, **백준(Baekjoon)**, **프로그래머스(Programmers)** 등의 사이트의 다양한 예제 및 기출 문제의 풀이 코드를 정리한 것입니다. **Python**을 사용하여 문제를 해결하였습니다.

## 주요 특징

- 알고리즘 문제 풀이 (문제 설명 미제공)
- 데이터 구조
- 최적화 기법

## 기술 스택

- **Python**
